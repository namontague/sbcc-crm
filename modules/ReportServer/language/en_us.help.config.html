Report Server

Use this page to configure settings to connect to report server

In the Report Server Options sub-panel, enter information for the following fields:

  • URL. Enter the web address of the Report Server
  • Base Folder. Enter the base folder for reports. This will be prepended to the report path.
  • Username. Enter the a username that has access to the reports you need.
  • Password Enter the password for the user.

To save your report server settings, click Save; click Cancel to exit the page without saving your changes.
